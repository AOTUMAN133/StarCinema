# 星空影院 — 设计规格（演员作品页）

> 来源：用户设计图稿 docs/design-assets/06-演员作品.jpg
> 基准分辨率：1920x1080 (16:9)，电视端 10-foot UI

## 一、整体结构（全屏剧照背景 + 人物信息 + 横向作品行）

```
┌──────────────────────────────────────────────────────────────┐
│ ★星光影院                                         20:45  [头像]│
│ ┌───────────────────────────────────────────────────────────┐│
│ │ (○ 林晚舟) 林晚舟(金色大字)              (右侧留白展示背景)  ││
│ │  代表作:《星际行者》《时光之城》《归途》| 中国 | 1990.08.16 ││
│ │  中国新生代实力派女演员，以细腻的表演和多变的角色塑造力      ││
│ │  深受观众喜爱。(2行简介)                                   ││
│ │ ┃作品年表(金竖线装饰+白色标题)                             ││

│ └───────────────────────────────────────────────────────────┘│
└──────────────────────────────────────────────────────────────┘
背景=演员高清剧照,左侧+底部黑色渐变遮罩
```

## 二、顶部栏

| 项 | 规格 |
|---|---|
| 左上 | 金色/暖黄 Logo 图标 + "星光影院" |
| 右上 | 时间 20:45 + 用户头像 |

## 三、人物信息区（左中上部）

| 项 | 规格 |
|---|---|
| 头像 | 左侧圆形，直径约 160-200px，**金色/暖黄圆形描边**（3-4px） |
| 姓名 | 头像右侧，大字号 Bold **金色**（林晚舟） |
| 元数据 | 一行 24px 浅灰："代表作:《星际行者》《时光之城》《归途》 | 中国 | 1990.08.16" |
| 简介 | 两行白色/浅灰，限宽不遮右侧 |

## 四、作品年表区（核心）

| 项 | 规格 |
|---|---|
| 标题 | "作品年表" 白色，**左侧金色竖线装饰**（宽 4-6px，高约标题） |
| 布局 | **横向海报行**（非网格），海报从左至右，行尾 ">" 提示可滑动 |
| 海报元素 | 海报内底部：中文主标题 + 英文副标题小字 |
| 海报下方 | 中文标题 + 年份（如 "星际行者 / 2023"） |
| 焦点态 | 海报金色发光边框 + 轻微放大/层级提升；**下方标题文字变金色**（年份保持白色） |

## 五、左下角操作提示

| 项 | 规格 |
|---|---|
| 内容 | "按 [◀▶方向键图标] 选择 · 按 [OK同心圆图标] 确认"（设计稿原字"按按"为笔误，实现时只留一个"按"） |
| 样式 | 暗灰色小字（18-20px），位于左下角 |

## 六、背景与全局

| 项 | 规格 |
|---|---|
| 背景 | 演员全屏剧照，左侧+底部黑色渐变遮罩，右侧画面保留 |
| 安全区 | 四周 60-80px |

## 七、实现要点（Android）

- 入口：电影/剧集详情页主演头像 → 点击跳转本页（Person 详情）
- 数据：EmbyClient getPersonDetail(id) + getPersonWorks(id)（旧项目有对应 API）
- 头像圆形金边：CircleImageView 或 BitmapShader + ring drawable
- 作品行：横向 RecyclerView，竖版海报卡，焦点放大+金框+文字变色
- 操作提示行：静态 TextView 放左下，同页所有焦点 View 共用
