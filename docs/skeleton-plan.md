# 星空影院 — 骨架计划

> 目标：按设计稿从零搭 UI 层，复用移植的内核/API/工具层。
> 第一版范围：抽屉导航 + 首页 + 媒体库页 + 详情页 + 播放页（播放页整体搬）。

## 一、架构总览

```
┌─ MainActivity (单 Activity + Fragment)
│   ├─ 左侧抽屉（固定入口菜单：首页/电影/电视剧/综艺/动漫/纪录片/演唱会/4K专区/合集）
│   ├─ HomeFragment    首页：Hero 轮播 + 内容行
│   ├─ LibraryFragment 媒体库：大标题 + 筛选标签 + 3×4 网格
│   ├─ DetailFragment  详情页
│   ├─ SearchFragment  搜索页
│   └─ SettingsFragment 设置页
├─ PlayerActivity (整体搬运，独立 Activity)
└─ 内核/API/工具（整体搬运）
```

## 二、导航设计

### 抽屉菜单（设计稿）
- 固定 9 项：首页 / 电影 / 电视剧 / 综艺 / 动漫 / 纪录片 / 演唱会 / 4K专区 / 合集
- 每项 = Emby 库映射：
  - 电影 → Emby 库（如 "Movies" 或按类型映射）
  - 电视剧 → Series
  - 综艺 → 综艺类库
  - 动漫 → 动漫库
  - 4K专区 → 4K 标签筛选
  - 合集 → Emby Collections
- **映射表做成配置**（放 PreferencesHelper 或常量），因为不同 Emby 服务器库名不同

### 焦点链
- ☰ 打开抽屉 → 焦点在抽屉第一项
- 抽屉内上下移动；选中 → 进入对应页面
- 主内容区焦点：标题(不可聚焦) → 筛选标签 → 网格
- 边缘不逃逸（吸收左右键）

## 三、页面骨架

### 3.1 首页 HomeFragment
```
Hero 大横幅（全宽 16:9，自动轮播6s + 手动左右切 + 聚焦暂停）
  ├─ 标题（白色大字号）
  ├─ 简介（一行省略）
  ├─ 立即播放按钮（金色胶囊）
  └─ 指示点（当前金色长条）
内容行1：行标题 + 横向海报列表（更多>）
内容行2：...
内容行3：继续观看（带进度）
```

### 3.2 媒体库页 LibraryFragment（设计稿已定）
```
顶部：大标题（56-64px Bold 白）+ 右上角 搜索/设置/WiFi/时间
筛选行：全部[选中金] / 最新 / 高分 / 年份▾ / 类型▾
网格：4 列 × 3 行（16:9 卡，无角标，左下标题白+评分金纯数字）
焦点：金色描边 3-4px + 外发光
```

### 3.3 详情页 DetailFragment（等设计稿）
- 大背景图 + 海报 + 标题 + 评分 + 简介 + 播放按钮
- 选集（剧集）/ 相关推荐

### 3.4 播放页 PlayerActivity（整体搬运）
- 手势：横滑快进 / 长按 2-3x / 双击±10s / 左亮右音
- 硬解切换按钮 / EXO+FFmpeg 软解 EAC3 / 字幕归一化

## 四、数据流

```
EmbyClient (API 层，搬运)
  ├─ getLibraries() → 抽屉映射
  ├─ getItems(libraryId, sort) → 媒体库网格
  ├─ getResume() → 继续观看
  ├─ getLatest() → 首页 Hero/行
  ├─ getItemDetail(id) → 详情
  └─ playSession → 播放会话
```

## 七、风险与对策

| 风险 | 对策 |
|---|---|
| Emby 库名映射不匹配 | 映射表做成可配置，首启可自动探测库名 |
| MPV AAR 依赖路径 | 从旧项目 libs/ 复制，本地构建 |
| 抽屉/焦点逃逸 | 参考旧项目 wireFilter 思路，但新代码更干净 |
| 设计稿页面不足 | 逐页向用户要图稿，先做已定的 |
