## 二、顶部栏

| 项 | 规格 |
|---|---|
| Logo | 左侧："星光影院"金字 + 品牌图标，字号 32-40px Bold 金 |
| 顶级导航 | Logo 右侧：首页(当前,金色下划线) / 搜索 / 设置，28-32px，选中项下方金色下划线 |
| 状态区 | 右侧：时间 20:45 + WiFi 图标，24-28px 浅灰 |

## 三、Hero 大横幅（首屏视觉中心）

| 项 | 规格 |
|---|---|
| 尺寸 | 全宽 16:9（1920 下 ≈ 1920x1080 内上 60% 区域），位于顶部栏下方 |
| 背景 | 单张整幅海报/剧照（图稿为奇幻剑客+城堡），**左下区暗化渐变**保证文字可读 |
| 主标题 | 大字号（56-80px）书法/粗体，白色，左下 |
| 副标题 | 主标题下方一行，24-28px 浅灰 |
| 标签 | "高分热播"金边框圆角小标签，位于副标题下/旁 |
| 指示点 | 横幅底部中央：当前=金色长条，其余=5 个灰色小圆点 |
| 轮播 | 多张轮播（后续 HomeFragment 实现：6s 自动 + 手动左右切，参考骨架计划） |

## 四、内容行（热门推荐 / 继续观看）

| 项 | 规格 |
|---|---|
| 行标题 | 左侧 32-40px Bold 白（"热门推荐"），右侧"更多 >"入口 24px 浅灰，可聚焦 |
| 热门推荐 | 横排竖版海报，每行 5-6 张，海报下标注 ★评分（金色）|
| 继续观看 | 横排横版封面（16:9），位于屏幕底部，露出半行提示可滚动；带播放进度状态（后续实现）|
| 滚动提示 | 行尾可滚动时右侧渐隐/截断，焦点按左右键滚动整行 |

## 五、焦点态（核心）

| 项 | 规格 |
|---|---|
| 左抽屉选中 | 金色发光描边圆角矩形底（同媒体库页） |
| 海报焦点 | **放大 1.05-1.1x + 金色发光边框 3-4px + 外发光模糊**，文字/评分随焦点变金 |

## 六、背景与全局

| 项 | 规格 |
|---|---|
| 背景 | 深暗灰 #0A0A0C ~ #111111（非纯黑） |
| 安全区 | 四周 60-80px 均匀边距（防 Overscan） |
| 对齐 | 左抽屉与主区严格左对齐一中线 |

## 七、实现要点（Android）

- HomeFragment 结构：Hero 区（ViewPager/手动切，骨架计划 Hero 轮播 6s + 聚焦暂停）+ RecyclerView 内容行（横向）
- 行焦点缩放：PivotLayoutManager 或 item onFocus 缩放动画（scale + elevation），金色描边用 GradientDrawable
- "更多 >"可跳媒体库页全网格
- 海报数据源：EmbyClient getLatest() / getResume()（见骨架计划数据流）
