**踩坑记录**：
- DpadRecyclerView 只支持 PivotLayoutManager，首页行必须用普通 RecyclerView + EdgeLockLinearLayoutManager（旧壳即如此）；媒体库/搜索网格用 DpadRecyclerView + PivotLayoutManager ✅
- 布局 layout_weight 不能写 "0f"/"100f"，必须 "0.0"/"100.0"
- BuildConfig 需要显式 import com.starcinema.BuildConfig
