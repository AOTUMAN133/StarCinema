## 一、项目概述

基于 Emby 内核的安卓 TV 端媒体播放器，暗金主题设计语言。「星月」为品牌符号，深色背景 + 金色强调色。

## 四、界面详解

### 01 App 图标
1:1 方角22%，纯黑底 #0A0A0A，立体金色五角星（3D金属切面）+ 双月牙金环 + 右上四角闪光星。渐变 #FFE082→#F5C542→#D4A017。

### 02 服务器添加页
顶栏：Logo+星光影院 / 右时间+头像。左40%：金色发光卡（黑圆加号+添加服务器）。右60%：服务器列表5项（图标+名称+地址+缩略图）。右下版本号。
交互：焦点"添加服务器"卡→金色光晕增强→确认进配置页；列表项聚焦金框→确认连接进首页；长按弹管理菜单；**首次默认焦点在"添加服务器"卡片**。

### 03 首页（重点）
**布局**：
- 左侧导航栏（**18%宽度**）：Logo + 9 分类导航项
- 顶部 Tab 栏：首页/搜索/设置 + 时间 + WiFi
- Banner 轮播区：**大幅横版海报**，左标题+副标题+标签，底部圆点指示器
- 热门推荐区：标题+"更多"，横向滚动 **6张竖版海报卡片**（含评分）
- 继续观看区：横向滚动**横版缩略图卡片**（含进度条）

**交互**：
- **左右键在导航栏与内容区间切换，上下键在列表内移动**
- Banner 自动轮播（**5秒/张**），焦点移入时暂停
- 海报卡片选中态：金色发光边框 + 轻微放大
- 确认进详情页，菜单键弹筛选
- 导航栏选中项：金色渐变胶囊背景 + 发光

### 04 电影详情页
背景大幅横版海报+左深色渐变遮罩。左信息区：金色书法大标题+装饰线；元信息行（年份·时长·⭐评分）；简介2行；按钮**立即播放（金色实心）+收藏（描边）**。相关推荐横版4张。
交互：默认焦点"立即播放"；右键→收藏→相关推荐；返回回上级；收藏点击实心金心+缩放反馈。

### 05 剧集详情页
背景横版海报+左遮罩。信息区：金标题+元信息+简介；按钮播放第一集+收藏；**主演区4个圆头像（选中金框）+姓名**；**分季标签（左右切换，确认刷新分集）**；分集列表横向横版卡（集数·标题·时长）；相关推荐横版。
交互：分季标签左右切换；分集卡金框+S02EXX；确认播放+自动记录进度；主演金框→演员作品页。

### 06 演员作品页
背景右侧剧照+左遮罩。大圆头像（金框）+姓名+代表作/国籍/生日+简介。作品年表：标题金色竖线装饰，横向6张竖版剧照（片名+年份倒序2023→2015）。底部操作提示。
交互：默认焦点第一张（最新）；左右切换；卡下同步片名年份；确认进详情。

### 07 搜索页
左导航18%+Logo+9分类。顶部大圆角搜索框（金框+放大镜），占位"搜索片名 / 演员 / 类型"。**热门搜索6个圆角标签横排**（选中金色实心带火焰）。大家都在看4张竖版海报。
交互：默认焦点搜索框→OK弹软键盘；实时搜索；下键→热门标签左右切换→选中即搜；再下→推荐区确认进详情。

### 08 媒体库页
左导航18%（选中金色胶囊）。主区顶部大标题"电影" + 右上搜索/设置/WiFi/时间。**筛选标签：全部/最新/高分/年份/类型 5个**。内容区：**4列×3行网格 12张横版海报**（海报+片名+评分）。右下分页3点。
交互：方向键网格移动；确认进详情；筛选刷新；年份/类型弹下拉；翻页；左导航切分类。

### 09 播放界面
全屏视频+弹幕层。顶栏半透明：返回+片名 / 时间+WiFi。底栏半透明：片名S02E03；**进度条金渐变+圆拖拽点+32:15/45:00**；控制按钮：**后退10秒、暂停（大号金色圆形突出）、快进10秒、上一集、下一集、倍速、音轨、字幕选择、弹幕、内核切换、字幕大小**。右下字幕大小面板（减/滑/加/120%）。
交互：5秒无操作自动隐藏（500ms淡出）；任意键唤起默认焦点暂停；**左右快进/快退10秒，长按持续**；上下在控制键间移动；进度拖拽；倍速/字幕/音轨弹面板；返回退出播放。

## 五、交互规范

### 遥控器按键映射
| 键 | 通用 | 播放界面 |
|---|---|---|
| 方向键 | 移动焦点 | 左右：快进/快退10秒；上下：唤起控制栏并移动 |
| OK | 激活元素/下一级 | 播放/暂停 |
| 返回 | 返回上级 | 退出播放回详情 |
| 菜单 | 上下文菜单（筛选） | 播放设置面板 |
| Home | 回首页 | 后台播放回首页 |
| 音量 | 系统音量 | 系统音量 |

### 焦点态规范
- **卡片**：2px 金色边框 + 金色发光阴影 + 放大（scale 1.03）
- **按钮**：金色渐变背景 + 强发光 + 上移 1px
- **导航项**：金色渐变胶囊背景 + 文字变金 + 发光
- **列表项**：背景金色半透明 + 左侧金色指示条
- 过渡：0.2s ease-out

### 动画
焦点移动200ms ease-out / 页面转场300ms ease-in-out / 卡片悬停200ms / 弹窗250ms cubic-bezier(0.34,1.56,0.64,1) / Banner轮播500ms / 控制栏隐藏500ms ease-in

### 适配
1920×1080 基准，支持4K自动缩放。**内容距屏幕边缘至少40px**。最小字号13px，正文15px（3米可读）。**所有可交互元素必须有明确焦点态，禁止无焦点反馈**。每次按键有视觉/听觉反馈。
