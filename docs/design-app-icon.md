# 星空影院 — 设计规格（APP 图标）

> 来源：用户设计图稿 docs/design-assets/01-APP图标.jpg
> 用途：Android TV 桌面 Launcher 图标（TV 端 320x320 生态，只留中安全区）

## 一、总体

黑金品牌图形，**无任何文字**，3D 金属质感（非扁平）。高对比黑金在暗背景 TV 桌面极醒目。

## 二、容器与背景

| 项 | 规格 |
|---|---|
| 形状 | 圆角方形（Squircle），平滑圆弧角（tvOS/Android TV 标准） |
| 背景色 | 深黑，带极微弱径向渐变（中心略亮 #121314 → 四角近 #000000），避免死黑 |
| 纹理 | 无网格/无噪点，纯色渐变 |

## 三、图形元素（中心 → 外围）

| 元素 | 规格 |
|---|---|
| 主图形 | 正五角星，居中，占图标约 55-60% |
| 星体造型 | 3D 倒角/浮雕：每角一条中央棱线把星面分成两个坡面，一侧受光一侧落影 |
| 环绕弧线 | 两条流线弧（月牙/星轨）：上弧左细→顶部最粗→右收尖；下弧反向镜像。两弧交错呈不闭合动感圆环，半包围五角星，弧宽约星体的 1/6~1/5 |
| 点缀 | 右上象限四角星芒（十字高光），带光晕（lens flare），位于轨道弧外侧 |
| 整体构图 | 星+弧形成稳定的圆形视觉中心，四角星芒平衡右上角 |

## 四、配色（金属金阶）

| 层次 | 色值感觉 |
|---|---|
| 高光（specular） | 亮白黄 #FFF2B2 ~ #FFD700 |
| 中间调 | 纯金黄 #DAA520 ~ #B8860B |
| 暗部/阴影 | 深古铜 #5C4033 ~ #3E2723 |
| 背景 | 近黑 #000000 ~ #111111 |

光效方向：主光源偏左上，星芒位于受光侧；高光点集中几处（不是全图泛光）。

## 五、实现要点（Android）

- 图标源用 **VectorDrawable + 渐变色**（LinearGradient 分坡面），圆角方形用 Android 12+ 自适应图标机制（background layer = 黑渐变，foreground layer = 星+弧+星芒）
- 3D 金属感：不做位图浮雕，用多层线性渐变 + 高光路径近似即可（TV 远距离观看，立体感弱化可接受）
- Launcher 图标：`adaptive-icon`，背景 #0A0A0C 径向渐变，前景星/弧金色系，安全区参考系统规范（内圈 66/108）
- 若需要启动页 Splash 同款图形：直接用 foreground 图形放大 + 背景渐变即可
