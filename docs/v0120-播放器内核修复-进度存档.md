## 一、本次完成（v0.12.0，versionCode 15）

**🔴 播放器内核遗留问题已修复**

**问题**：盒子上播放器启动即崩（UnsatisfiedLinkError）
**根因**：AAR（mpv-android-lib-0.1.12-fongmi.aar）内 `jni/armeabi-v7a/` 全部是 **64 位 aarch64 ELF**（伪32实64），而小米盒子是纯 32 位系统 → 加载失败

**修复**：从 EmbyTV 复制整套真 32 位 jniLibs（10 个 so）到 StarCinema：
```
app/src/main/jniLibs/armeabi-v7a/{libmpv,libplayer,libavcodec,libavformat,
  libavfilter,libavutil,libavdevice,libswresample,libswscale,libc++_shared}.so
```
- jniLibs 同名 so 自动覆盖 AAR 内假 64 位（打包已验证，APK 内 file 显示真 32 位）
- arm64-v8a 不受影响（继续用 AAR 真 64 位）
- 全部 so 已入 git（与 EmbyTV 惯例一致）

**装盒验证（小米盒子 192.168.1.147）**：
- ✅ v0.12.0 armeabi-v7a debug 包成功覆盖安装（盒子现有包是 **debug 签名**，不是 release.keystore！装盒用 debug 包即可覆盖，release 包会 INSTALL_FAILED_UPDATE_INCOMPATIBLE）
- ✅ 进入详情页 → 点"立即播放" → **PlayerActivity 正常进入，零崩溃**
- ✅ EXO 内核全通：setSurface valid=true → play() → ASS 字幕挂载 → 视频帧渲染
- ✅ MPV 内核加载成功：MPVLib[ffmpeg]/[stream]/[ytdl_hook] 正常跑，UnsatisfiedLinkError 彻底消失（MPV 内核在盒子上现在可用了）
- ⚠️ 当前测试影片（openani.an-i.workers.dev 源）盒子网络 TCP 443 超时，播不出画面——**源/网络问题非 App 问题**（开发机可连该源，返回 429 限流；盒子网络无法直连 workers.dev）

## 二、构建与装盒备忘（重要！）

| 项 | 说明 |
|---|---|
| 装盒包 | **debug 签名**（apksigner 验证现有包 CN=Android Debug） |
| debug 包可覆盖 | `adb install -r app-armeabi-v7a-debug.apk` |
| release 包 | 覆盖失败 INSTALL_FAILED_UPDATE_INCOMPATIBLE（除非先卸载） |
| 构建命令 | `./gradlew assembleDebug`（1m18s，无 R8）双 ABI 出品 |
| 验证 APK 内 so | `unzip -p app.apk lib/armeabi-v7a/libmpv.so > /tmp/m.so && file /tmp/m.so` → 应为 ELF 32-bit ARM EABI5 |
| APK 在 | /root/传输/StarCinema_v0.12.0_{armeabi-v7a,arm64-v8a}.apk（v0.11.0 旧版已删） |
