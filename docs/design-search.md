## 二、搜索框（主元素）

| 项 | 规格 |
|---|---|
| 位置 | 右侧主区顶部，占主区大部分横向宽度 |
| 样式 | 大尺寸圆角矩形（胶囊），圆角 = 高度一半 |
| 内部 | 左侧放大镜图标 + 占位文字 "搜索片名 / 演员 / 类型" + 右侧光标 "|" |
| 聚焦态 | **金黄色/橙色弥散发光边框** + 光标闪烁（提示可输入） |
| 未聚焦 | 深灰半透明底 + 浅灰占位文字 |

## 三、热门搜索区

| 项 | 规格 |
|---|---|
| 标题 | "热门搜索" 白色 |
| 布局 | 横向药丸标签（pill），遥控器左右滑动选择 |
| 标签元素 | 可选火苗图标；文字 24px |
| 选中态 | 金色/高亮背景 + 黑字（图稿中"科幻巨制"高亮） |
| 未选中 | 深灰底 + 浅灰字 |
| 标签集 | 科幻巨制 / 年度佳片 / 高分悬疑 / 经典国漫 / 音乐会现场 / 纪录片精选 |

## 四、默认推荐区（未输入时）

| 项 | 规格 |
|---|---|
| 标题 | "大家都在看" 白色 |
| 布局 | 横排海报（竖版），4 张直达，可横向滚动（carousel） |
| 卡片 | 竖版海报 + 下方标题(白) + 年份(浅灰小字) |
| 焦点 | 金色发光边框 + 放大 |

## 五、输入交互（图稿未画键盘，按 TV 规范补全）

1. 搜索框聚焦 → 按 OK 呼出**屏幕软键盘**（全键盘 QWERTY 或 T9 拼音，覆盖热门搜索区）
2. 方向键移动键盘焦点，OK 输入，返回键收起
3. 输入过程中：热门搜索区 → 替换为**联想词列表**（垂直/横向），选词即搜
4. 输入后 → 结果区替换"大家都在看"为结果网格
5. 支持遥控器语音键输入（如硬件支持）
6. 搜索历史：设计稿未画出，作为可选模块（有历史时显示在搜索框下方）

## 六、背景与全局

| 项 | 规格 |
|---|---|
| 背景 | 深黑/暗灰 #0A0A0C ~ #111111 |
| 文字层级 | 白(主)/浅灰(次)/深灰(占位) |
| 焦点色 | 金黄/渐变橙，黑色背景下 3 米外可辨 |

## 七、实现要点（Android）

- 搜索框：EditText 自绘背景（未聚焦深灰 pill / 聚焦金色 stroke+shadowLayer），focus 监听切换
- 键盘：复用旧项目（EmbyTV 有搜索+键盘逻辑）或系统 IME；TV 端优先自绘键盘
- 联想：TextWatcher 防抖 300ms → EmbyClient search() → 联想列表
- 热门标签：横向 RecyclerView pill 样式
- 推荐区：横向 RecyclerView 4+ 海报
- 复用骨架：左抽屉共用组件，右侧主区替换为 SearchFragment
