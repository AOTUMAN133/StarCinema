## 二、🔴 播放器内核遗留（未修，下一步）

**问题**：盒子上播放器启动即崩
**根因**：`UnsatisfiedLinkError: lib/armeabi-v7a/libmpv.so is 64-bit instead of 32-bit`
**关键发现**（用户质疑"滴滴TV为什么没问题"后排查得出）：

| | 滴滴TV (EmbyTV) | 星光影院 (StarCinema) |
|---|---|---|
| AAR | libs/mpv-android-lib-0.1.12-fongmi.aar | 同款 AAR |
| app/src/main/jniLibs/armeabi-v7a/libmpv.so | ✅ 存在（真 32 位，能跑） | ❌ 不存在（只有 port/ 副本） |

**修复方案（已验证思路）**：
```
cp /root/EmbyTV/app/src/main/jniLibs/armeabi-v7a/libmpv.so \
   /root/StarCinema/app/src/main/jniLibs/armeabi-v7a/libmpv.so
```
- 复制后重新构建，装盒验证播放器
- 附带验证：该 so 是否真 32 位（file 命令对比 AAR 内的）

**盒子环境备忘**：
- 小米盒子 192.168.1.147:5555，ABI=armeabi-v7a（纯 32 位系统）
- arm64-v8a 包装不上（install 失败），只能用 armeabi-v7a 包
- 当前装的是 v0.11.2 armeabi-v7a（versionCode 14）
