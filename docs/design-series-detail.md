| 项 | 规格 |
|---|---|
| 主按钮"播放第一集" | 亮黄色实心胶囊 + **黑色**文字，播放三角图标，聚焦放大+外发光 |
| 次按钮"收藏" | 透明底 + **细黄色边框**，白色文字/加号图标 |

| 项 | 规格 |
|---|---|

## 七、分集列表区（本页核心）

| 项 | 规格 |
|---|---|
| 标题 | "第2季 · 共10集" 白色 |
| 布局 | 横排长方形卡片（封面图），支持向右滑动 |
| 卡片元素 | 封面右上角**半透明黑底时长角标**（42:16）；卡片下方 "S02E01 新的边界"（集数+集名） |
| 焦点/高亮 | 金色粗发光边框 + **卡片略放大**（焦点=当前选中集，含上次观看位置） |
| 滑动提示 | 行尾白色 ">" 箭头 |
| 示例 | S02E01 42:16 / S02E02 41:52 / S02E03★ 43:28 / S02E04 42:03 / S02E05 41:37 / S02E06 44:12 |

| 焦点 | 金色边框+放大 |

## 九、实现要点（Android）

- 结构：DetailFragment 支持"电影/剧集"两种模式（电影无分季/分集区）
- 分季胶囊：横向 RecyclerView/LinearLayout，选中切金底黑字
- 分集卡：横向 RecyclerView，16:9 封面 + 右上时长角标（半透明黑 pill）+ 下方两行文字
- 播放逻辑：点集卡 → 传 episodeId 进 PlayerActivity（整体搬运）
- 数据：EmbyClient getSeasons(seriesId) + getEpisodes(seasonId)，上次观看位置 getUserData → 集卡高亮
