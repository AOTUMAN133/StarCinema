## 二、左侧导航抽屉

| 项 | 规格 |
|---|---|
| 宽度 | 屏幕宽 18-20%（1920px 下 ≈340-380px）|
| Logo | "星光影院" + 金色星标，字号 36-40px Bold，金色 #F2C97D~#E8B65C，距顶 60-80px、距左 50-60px |
| 菜单项高度 | 56-64px |
| 菜单项间距 | 24-32px |
| 图标 | 28-32px 线框图标 |
| 文字 | 28-32px Regular |
| 选中项 | 金色胶囊（全圆角=高度一半），**左亮右暗渐变 + 金色外发光**，色 #E5B869 → 半透明棕 |
| 滚动指示 | 列表上下端有 ^ v 箭头（菜单项多时可滚动）|
| 菜单项顺序 | 首页 / 电影 / 电视剧 / 综艺 / 动漫 / 纪录片 / 演唱会 / 4K专区 / 合集 |

## 五、海报网格

| 项 | 规格 |
|---|---|
| 布局 | **3 行 × 4 列** = 12 张/屏（4 列宽）|
| 卡片宽高比 | 16:9 宽屏 |
| 圆角 | 12-16px |
| 间距 | 水平/垂直 32-40px（等距）|
| 海报内标题 | 左下角，24-26px 纯白 |
| 海报内评分 | 标题正下方，18-20px 金色 #FFB400 |
| 底部遮罩 | 底部→上黑色线性渐变（底 80-100% → 顶 0%），保证亮色海报上文字可读 |
| 更多提示 | 右下角最后一个卡片有"..."（可滚动提示）|

## 六、焦点态（Focus）

| 项 | 规格 |
|---|---|
| 边框 | 3-4px 金色描边，圆角略大于海报（16-20px）|
| 发光 | 外发光 Drop Shadow，模糊 15-20px，同金色 |
| 触发 | 遥控器方向键移动焦点（第二行第一张为例）|

## 七、背景与全局

| 项 | 规格 |
|---|---|
| 背景色 | 非纯黑，深暗灰 #0A0A0C ~ #111111 |
| 环境光 | 左侧抽屉选中项附近有极暗金色环境光晕 |
| 安全区 | 四周 60-80px 均匀安全边距（防 Overscan 裁切）|
| 对齐 | 严格左对齐：抽屉 Logo/菜单图标/底部箭头 一条线；主区标题/筛选组左缘/海报第一列 一条线 |
| 亲密性 | 海报内标题-评分间距最小 < 筛选标签间距 < 卡片间距 < 区域间距 |

## 八、实现要点（Android）

- 色值常量：star_gold=#E8B65C、star_bg=#0A0A0C、star_text=#FFFFFF、star_text_secondary=#A6A6A6
- 焦点样式：GradientDrawable stroke 3-4dp + setShadowLayer(模糊) 模拟外发光
- 网格：DpadRecyclerView + PivotLayoutManager spanCount=4，卡片 16:9
- 海报文字遮罩：底部黑色渐变 View
- 筛选标签：Pill Shape（radius=高度/2），选中切背景+文字色
- 抽屉：侧滑（可参考旧项目 onGlobalLeftKey 模式，但按新设计稿重做）
