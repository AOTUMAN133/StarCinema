# 星空影院 — 设计规格（播放界面页）

> 来源：用户设计图稿 docs/design-assets/08-播放界面页.jpg
> 基准分辨率：1920x1080 (16:9)，电视端 10-foot UI
> 说明：播放内核（EXO/MPV）整体搬运自旧项目，本规格只约束 UI 层控件样式

## 二、顶部遮罩与信息

| 项 | 规格 |
|---|---|
| 遮罩 | 屏幕上缘黑色半透明线性渐变（向下渐透明），保证白字可读 |
| 左侧 | 返回箭头 + 主标题"星际远征"（白，28-32px） |
| 右侧 | 时间 20:48（浅灰） |

## 三、弹幕区（可选模块）

| 项 | 规格 |
|---|---|
| 位置 | 屏幕中上部，悬浮于画面 |
| 颜色 | 多色：橙/浅蓝/粉紫/绿（用户发言）+ 灰半透明（普通） |
| 样式 | 从右向左滚动，不同透明度 |
| 开关 | 控制栏"弹幕"按钮控制显隐 |

## 四、底部控制栏（核心）

### 4.1 播放信息行

| 项 | 规格 |
|---|---|
| 左侧 | 剧集信息"星际远征 S02E03"（白 24px） |
| 右侧 | 播放时间"32:15 / 45:00"（浅灰 24px） |

### 4.2 进度条

| 项 | 规格 |
|---|---|
| 样式 | 极简水平线条，**无边框** |
| 已播部分 | 金黄色高亮 |
| 未播部分 | 暗灰色 |
| 滑块 | **金黄色发光圆点**，精确位于进度位置 |
| 圆点显隐 | 仅聚焦时显示（参考旧项目定稿：默认隐藏，聚焦 thumbColor+thumbRadius） |

### 4.3 操作按钮排（11 个，从左到右）

| # | 按钮 | 图标 | 说明 |
|---|---|---|---|
| 1 | 后退10秒 | ⏪⏪ | 双左箭头+竖线 |
| 2 | 播放/暂停 | ⏸/▶ | **主按钮，聚焦=金黄色发光圆圈** |
| 3 | 快进10秒 | ⏩⏩ | 双右箭头 |
| 4 | 上一集 | ◀\| | 左箭头+竖线（剧集） |
| 5 | 下一集 | \|▶ | 右箭头+竖线（剧集） |
| 6 | 倍速 | 仪表盘 | 当前值 x1.5 |
| 7 | 音轨 | 音符 | 切换音轨 |
| 8 | 字幕选择 | 对话□ | 切换字幕轨道 |
| 9 | 弹幕 | 笑脸对话 | 弹幕开关 |
| 10 | 内核切换 | "EXO"字样 | 硬解内核切换（EXO/MPV） |
| 11 | 字幕大小 | "A+"字样 | 展开字幕大小面板 |

按钮样式：圆形/胶囊图标按钮，图标+下方说明文字（18-20px）；未选中白/浅灰，选中金黄发光。

### 4.4 展开面板（以字幕大小为例）

| 项 | 规格 |
|---|---|
| 锚定 | 面板底部居中所属按钮上方，带向下小箭头指向按钮 |
| 背景 | **半透明暗黑** + 细金色边框 |
| 标题 | "字幕大小调节" 白 |
| 滑块 | 左侧"-"、中间金色滑条+金色圆点、右侧"+"；当前值 "120%" |
| 方向键 | 左右键直接控制滑块（参考旧项目定稿） |

## 五、配色与全局

| 项 | 规格 |
|---|---|
| 主题 | 暗夜黑 + 流光金 |
| 焦点色 | 金黄发光：进度条、滑块、按钮圈、面板边框 |
| 普通文字 | 白色/浅灰 |
| 遮罩 | 顶部+底部黑色半透明渐变（不遮挡画面主体） |

## 六、实现要点（Android）

- 播放内核整体搬运（PlayerActivity 旧代码），UI 控件按本规格重做样式
- 控制栏闲置 5s 自动隐藏（旧项目定稿）；返回键分层：先藏控制栏再退出
- 手势保留（旧项目定稿）：横滑快进（松手 seek）/ 长按 2-3x / 双击±10s / 左亮右音浮点 % / 沉浸全屏 / 右上角硬解内核切换
- 进度条：自绘 View（金色已播 + 灰未播 + 聚焦圆点 thumbColor/thumbRadius）
- 字幕规范化沿用旧项目（ASS 按 PlayResY、PGS 按屏高%）
- EAC3 软解：EXO+FFmpeg 配置保留
