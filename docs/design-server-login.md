## 二、顶部栏

| 项 | 规格 |
|---|---|
| 左上 | Logo：金标 + "星光影院" 金字 |
| 右上 | 时间 12:41 + 用户头像（圆形入口）|

## 三、左侧"添加服务器"大卡片（主操作）

| 项 | 规格 |
|---|---|
| 位置 | 左侧约 1/3 宽，垂直居中 |
| 形状 | 大号长方形卡片，明显圆角（24-32px） |
| 背景 | **金黄色渐变填充** + 金色外发光 |
| 内部 | 正中深灰色圆形（直径约卡片高 1/3），内置金色"+"号；下方黑色文字"添加服务器"（大字号，约 32-36px Bold 黑字） |
| 焦点 | 同卡片常态即高亮（本身即主入口）；聚焦时外发光增强/放大 |

## 四、右侧服务器列表

| 项 | 规格 |
|---|---|
| 位置 | 右侧约 2/3 宽 |
| 条目 | 横向长条卡片，圆角 16-20px，**半透明深灰底**（rgba 白 0.08-0.12），默认无边框 |
| 条目内部 | 左侧服务器类型图标（NAS/云/机架 24-28px）→ 中间名称(28-32px 白) + 地址/IP(24px 浅灰) → 右侧自定义封面图 |
| 焦点态 | **明亮的金色发光边框**（3-4px + 外发光模糊 15-20px），聚焦项文字金色 |
| 示例数据 | 家庭NAS 192.168.1.100 / 云端影院 emby.example.com / 影音服务器 192.168.1.88 / 阿里云影院 aliyun.example.com / 公司媒体库 192.168.0.120 |

## 五、其他元素

| 项 | 规格 |
|---|---|
| 版本号 | 右下角小字 18-20px 暗灰 "v3.2.0"（可行 Future 显示实际版本） |
| 背景点缀 | 左下角 2-3 道极弱金色光影线条（非必需，增强层次） |

## 六、交互流程（后续实现）

1. 首启/无服务器：显示本页
2. 聚焦"添加服务器"按 OK → 进入输入页（服务器地址 + 账号/密码，二级页）
3. 已有服务器列表 → 选中即连接（可长按编辑/删除）
4. 连接成功进首页；失败 toast 提示并停留

## 七、实现要点（Android）

- 两个 RecyclerView/线性布局：左大卡可当单个焦点 View（FocusScale + 金色渐变背景 GradientDrawable）
- 服务器列表项：CardView/LinearLayout 圆角渐变背景，onFocus 切金色 stroke + shadowLayer
- 数据：PreferencesHelper 存服务器列表（IP/名称/封面/类型），首启空列表只显示添加卡 + 空态提示
- 注意：此页**没有 IP 输入控件**，输入交互在点击后的二级页实现（参照旧项目 ServerActivity 逻辑，UI 重做）
