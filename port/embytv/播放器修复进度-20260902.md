## 待用户验证（v1.3.40 修复项）
1. **Emby 切集上报"时报时不报"** → 修复：switchGeneration 切集代数守卫
   - 根因：旧文件 END_FILE 事件迟到（切集后新集 onPrepared 清了 suppressAutoNext，旧 END_FILE 才到）
   - 修法：PlayerViewModel 加 `switchGeneration`/`preparedGeneration`，switchInQueue 时 ++，onPrepared 记录，
     onCompletion 代数不符 = 迟到旧事件 → 直接忽略（不上报/不乱切）
2. **MPV 切集后暂停键卡死**（一直是播放样子、无法暂停）→ 修复：eofReached 污染
   - 根因：paused 复位（v1.3.39 做过）不够，旧文件 END_FILE 把 eofReached=true → isPlaying() 恒 false
   - 修法：MpvVideoPlayer `MPV_EVENT_START_FILE` + `MPV_EVENT_FILE_LOADED` 双重复位 eofReached=false
3. **上滑面板媒体信息不随选集更新**（标题/简介/海报停在进界面那集）→ 修复：refreshMediaInfo
   - 根因：loadVideoInfo() 只在 onCreate 调一次
   - 修法：PlayerActivity 加类级 embyBaseUrl/embyApiKey 字段 + refreshMediaInfo()
     （从 playQueue 当前集 URL 提取 itemId → loadVideoInfo），挂在 refreshEpisodeHighlight() 里，
     覆盖选集/上/下一集三条路径
