> 来源：用户设计图稿 docs/design-assets/04-电影详情页.jpg
> 基准分辨率：1920x1080 (16:9)，电视端 10-foot UI

## 二、顶部栏

| 项 | 规格 |
|---|---|
| 左上 | 金色空心五角星图标 + "星光影院"（白/浅灰文字） |
| 右上 | 时间 20:45 + 用户头像圆形入口 |

## 三、信息区（左上，左对齐）

| 项 | 规格 |
|---|---|
| 标题 | "星际远征"，最大字号（56-72px）Bold，**金色** |
| 元数据 | 一行 24-28px 白："2024 · 135分钟 · ★ 8.9"（★星形图标金色，评分突出） |
| 简介 | 28px 白常规，限宽（约 700-800px，不遮右侧画面），3 行以内省略 |

## 四、操作按钮（简介下方，横向两个）

| 项 | 规格 |
|---|---|
| 主按钮"立即播放" | 金色实心底 + **黑色**文字/图标，播放三角图标+文字，胶囊或圆角 20px+，聚焦态放大+外发光 |
| 次按钮"收藏" | 透明底 + 细白/灰边框，白色文字/＋图标，聚焦时边框变金 |

## 五、主演区

| 项 | 规格 |
|---|---|
| 标题 | "主演" 金色（或白色小字），位于按钮下方 |
| 布局 | 横排圆形头像列表（横向滑动）|
| 头像 | 直径约 96-120px 圆形，下方姓名 24px 白 |
| 焦点 | 头像外围金色光圈（3-4px），聚焦放大 |
| 滑动提示 | 行尾半遮挡圆 + ">" 箭头 |

## 六、相关推荐区

| 项 | 规格 |
|---|---|
| 标题 | "相关推荐"（白色/金色，与主演标题一致） |
| 布局 | 横排 16:9 长方形海报卡片 |
| 卡片文字 | 左下角：主标题白 + 副标题/标语浅灰小字 |
| 焦点 | 金色发光边框 + 放大 |

## 七、背景与全局

| 项 | 规格 |
|---|---|
| 背景 | 整幅电影海报全屏，**左侧+底部黑色渐变暗化**（保文字可读），右侧主体画面保留 |
| 安全区 | 四周 60-80px |
| 无画质标签 | 设计稿中无 4K/蓝光/HDR 标签（实现时按需可在元数据行加，但不强制） |

## 八、实现要点（Android）

- 背景：ImageView 全屏 + 左侧 LinearGradient 遮罩（黑→透明，左→右）+ 底部竖渐变
- 按钮焦点：FocusStyleHelper（金色 stroke + shadowLayer + scale）
- 主演头像：RecyclerView 横向，圆形 ImageView + 焦点金色 ring
- 相关推荐：横向 RecyclerView 16:9 卡
- 数据：EmbyClient getItemDetail(id) + getPeople(Fields=People) + getSimilar（参考旧项目魔改经验：People/Favorite 404 用 Fields=People 修）
