## 一、设计系统定稿

| Token | 值 | TV 用途 |
|---|---|---|
| 背景 | #FFFFFF | 全局底色 |
| 分区背景 | #F5F7FA | 列表项/卡片 |
| 次级分区 | #F2F2F2 | 分组头/间隔 |
| 分割线 | #EBEBEB | 分隔 |
| 文字主 | #000000 | 标题 |
| 文字次 | #6E6E73 | 副标题/辅助 |
| 文字弱 | #9A9AA0 | 禁用/占位 |
| Accent | #55CBFF（亮蓝）| 选中/进度/按钮主色 |
| Accent 深 | #007AFF（系统蓝）| 可点文字/图标 |
| 成功 | #34C759 | 状态 |
| 警示 | #FF3B30 | 删除/警告 |
| 播放背景 | #002020（墨蓝黑）| 播放器全屏底色 |

### 1.2 字体
- 主字体：**PingFang SC（苹方）**——SenPlayer 打包 PingFangSC-Regular.otf；TV 端 Android 用系统字体即可（思源黑体/Noto Sans CJK 视觉接近）
- 层级（TV 大字规范，1080p 基准）：
  | 层 | 字号 | 字重 | 用途 |
  |---|---|---|---|
  | 大标题 | 44sp | Bold | 页面标题 |
  | 屏标题 | 36sp | Bold | 页面/区块 |
  | 行标题 | 30sp | Bold | 首页行 |
  | 卡片标题 | 20sp | Medium | 卡片内标题 |
  | 正文 | 22sp | Regular | 描述/详情 |
  | 辅助 | 18sp | Regular | 元信息 |
  | 徽章 | 16sp | Semibold | 标签/计数 |

### 1.3 布局 Tokens
| Token | 值 |
|---|---|
| 卡片圆角 | 12dp（列表）/ 16dp（大卡）|
| 卡片间距 | 24dp |
| 屏边距 | 48dp（左）/ 40dp |
| 行标题下距 | 20dp |
| 行垂直间距 | 28dp |
| 按钮高度 | 56dp |
| 焦点边框 | 4dp accent |
| 卡片阴影 | 0（iOS 扁平）→ TV 用 4dp elevation + 聚焦提升 |

## 二、每屏 TV 布局推演

### 2.1 首页（MainHome）
```
┌────────────────────────────────────────────┐
│ [大标题 44sp]                     [设置⚙]    │ ← 顶栏(半透明)
├────────────────────────────────────────────┤
│  ▶ 继续观看(ContinueWatching)               │
│  [横卡] [横卡] [横卡]  ← 2:3 海报横排        │
│                                             │
│  下一集(NextUpWatching)                     │
│  [横卡带"下一集"标签] [..]                   │
│                                             │
│  最新(Latest) / 推荐(Recommend)             │
│  [竖卡网格 Grid] [..]                       │
└────────────────────────────────────────────┘
```
- 顶栏：页名大标题（滚动收起，largeTitle 风格）+ 右侧设置/搜索图标
- 行标题：30sp Bold 黑 + 右侧"查看全部 SeeAll"
- 继续观看卡：横卡（2.35:1）带进度条 + 剩余时间
- 网格卡：竖卡 2:3，圆角 12dp，白底，聚焦 4dp accent 边框 + 轻微放大(1.06x)
- 未看数徽章：右上角红胶囊

### 2.2 详情页（Detail）
```
┌────────────────────────────────────────────┐
│  [背景 Backdrop 全屏，浅色蒙层/深色沉浸二选一] │
│  ┌──────────────────────────────────┐     │
│  │ 片名 44sp Bold                    │     │
│  │ 年份·时长·评分★ 18sp 次文字        │     │
│  │ [▶ 播放] [＋ 收藏] [✓ 已看]       │     │  ← 操作按钮行
│  └──────────────────────────────────┘     │
│  简介 22sp                                 │
│  ── 剧集列表(Episodes) ──                  │
│  [S1E1] [S1E2] [S1E3]  ← 竖向列表/横向排   │
│  ── 演职员(Cast) ──                        │
│  [头像] [头像] [头像]                      │
│  ── 相似作品(SimilarWorks) ──              │
│  [竖卡] [竖卡]                             │
└────────────────────────────────────────────┘
```
- 背景：Backdrop 全屏 + 底部渐变（沉浸式，SenPlayer 播放场景深色 → 详情页可深色头图 + 白色内容区）
- 操作按钮：56dp 高，主按钮 accent 填充圆角 16dp，次按钮白底描边
- 剧集列表：横向滚动卡（集号 + 缩略图 + 时长），聚焦高亮
- 演职员：圆形头像 120dp + 名字 18sp

### 2.3 播放器 OSD（暗色，KSPlayer 内核）
```
┌────────────────────────────────────────────┐
│ ← 返回     片名 22sp            右上：投屏  │ ← 顶栏（自动隐藏）
│                                            │
│                                            │
│                  ⏸ 70dp                   │ ← 中央主按钮
│                                            │
│ ┌──────────────────────────────────────┐  │
│ │ ●────────○────────○     01:23/45:00  │  │ ← 进度条 14dp 高, 圆点12dp
│ └──────────────────────────────────────┘  │   亮蓝进度 #55CBFF
│ ⏪ -10s  ▶ 倍速 1.0x  ⏩ +10s  音轨 字幕   │ ← 底部控制排(56dp)
└────────────────────────────────────────────┘
```
- 底色 #002020 墨蓝黑（官方 TV 截图确认）
- 控制栏自动隐藏（5s 无操作）/ 半透明黑底 + 毛玻璃
- 手势（SenPlayer 全平台统一）：
  - 左竖滑 → 亮度 / 右竖滑 → 音量
  - 双击左半屏 → 快退 / 双击右半屏 → 快进（可设 10/15/30s）
  - 长按 → 倍速 / 单击 → 播放暂停
  - 横滑 → 进度（松手定位 + 预览）
- 跳过按钮：白底黑字胶囊（"跳过片头 16sp Bold"）
- 上滑面板：音轨/字幕/倍速/画面比例/解码模式（硬解/软解）

### 2.4 弹幕系统（Danmaku）
- 开关：弹幕开/关，位置（顶部/底部/浮动），速度，字号，字体，**关键词屏蔽**，弹幕源（自定义 API）
- TV 显示：弹幕行高 36dp，半透明白字黑描边，顶部/底部区域

### 2.5 字幕系统
- **双字幕**（主/副字幕同时显示），在线搜索（内置脚本/JSScript），缓存目录，字号/颜色/位置/时间偏移，防遮挡，繁简转换
- TV 显示：字幕 20sp 白字黑边，底部居中，双字幕上下排列

### 2.6 设置页
- 分组列表（浅色）：通用 / 播放 / 弹幕 / 字幕 / 手势 / 界面 / 媒体库 / 列表 / 视频 / 音频
- 界面组：**主题色选择器（6色）** / 深浅色 / 大标题或小标题 / 网格或单列 / 显示项开关
- 服务器管理：Emby/Jellyfin/Plex + 网盘（115/阿里/百度/123/WebDAV/SMB/FTP）+ IPTV
- 手势设置：各手势开关 + 快进时长
- 播放设置：硬解/软解切换、跳过片头片尾（ED/OP 时间点）、预加载下一集、倍速列表
- 信息：应用版本、反馈（QQ群/邮箱/小红书）

### 2.7 网盘/文件浏览（TV 适配）
- 左栏服务器列表（服务器+协议图标）+ 右侧文件网格/列表
- 文件卡：图标 + 文件名 20sp + 大小/时间 16sp，聚焦 accent 边框
- 排序：名称/大小/日期（SenLib strings 确认 sort_name/sort_size/sort_date）

## 三、动效规范
| 场景 | 动画 |
|---|---|
| 聚焦 | 缩放 1.06x，200ms easeOut + 4dp accent 边框 |
| 页面切换 | 淡入 250ms |
| 进度条 | 即时（拖动实时）|
| 控制栏显隐 | 上下滑动 200ms + 自动隐藏 5s |
| 背景切换 | 交叉淡化 300ms |

## 四、TV 焦点系统
- 焦点：**4dp accent 边框（#55CBFF）** + 卡片 1.06x 缩放 + 阴影提升
- 3 米外清晰度：边框 ≥4dp、文字 ≥16sp
- 焦点记忆：返回保留位置
- 渐变焦点环（可选）：聚焦卡片描边从 accent 到透明渐变
